Pro Tips

Get the Best EPUB to PDF Results

Choose A5 or B5 for Print Books
tip → page size
Most trade paperbacks are B5 (176 × 250 mm) or A5 (148 × 210 mm). If you're printing to bind as a physical book, use one of these sizes rather than A4 so the proportions match a real book rather than an office document.
16 pt Serif for Comfortable Reading
tip → typography
For long-form reading, 16 pt Georgia (serif) at 1.6 line spacing is generally the most comfortable on screen and in print. Use 14 pt for dense reference books where you want more text per page, and 18 pt for large-print layouts.
Exclude Front & Back Matter
tip → chapter selection
Most EPUBs include title pages, copyright notices, dedication pages, acknowledgements, and index sections as separate "chapters". Deselect these if you only want the main content — it reduces the page count significantly in long books.
Compress After Converting
tip → file size
EPUBs with many high-resolution embedded images produce large PDFs. After downloading, run the PDF through Compress PDF to reduce the file size significantly without visible quality loss — useful for emailing or uploading to cloud storage.
Protect Before Sharing
tip → access control
If you're sharing a converted ebook PDF you authored, use Protect PDF after converting to add a password and restrict copying — so the content can be read but not easily extracted or redistributed.
DRM-Protected EPUBs Cannot Be Converted
tip → DRM files
EPUBs protected with Adobe DRM (ADEPT), Apple FairPlay, or Kobo DRM cannot be opened without the DRM key. The tool will fail to parse these files. DRM removal requires the Adobe Digital Editions credential tied to your account — this tool does not and cannot remove DRM.

Why JPG2Go eBook to PDF Converter?

EPUB is a ZIP archive containing HTML/XHTML chapter files, CSS stylesheets, images, and a metadata file (OPF/content.opf). This tool uses JSZip to unpack the EPUB in-browser, then reads the OPF manifest and spine to discover chapters in their intended reading order. Metadata — title, author, language, cover image — is extracted from the Dublin Core fields in the OPF.

Each selected chapter's HTML is parsed to extract its text and structure: headings, paragraphs, lists, and emphasis. The cleaned text is then reflowed onto PDF pages using pdf-lib's text drawing API, respecting your chosen font size, line spacing, and margins. Headings are printed larger and bold. Paragraphs are wrapped to fit the page width. Pages are added automatically as text fills them.

This approach produces a clean, reflowed PDF rather than a screenshot-based one — the result is selectable, searchable text at your chosen typography, not a pixelated render. Images embedded in chapters are extracted, decoded, and placed inline at their natural position in the text flow.
