Pro Tips

Get the Best Results

Multi-Page TIFFs
tip → multi-page
When you upload a multi-page TIFF (common from document scanners and fax archives), the tool reads every IFD in the chain. Page count is detected and displayed before conversion. A 50-page scanned TIFF produces a 50-page PDF with page order preserved exactly.
Large File Warning
tip → file size
Uncompressed TIFFs can be very large — a 300 DPI A4 scan at 24-bit colour is ~25 MB. Parsing large TIFFs is memory-intensive. For files over 50 MB, allow 10–30 seconds and use a desktop browser. Mobile devices may run out of memory on very large uncompressed TIFFs.
Unsupported Compressions
tip → compatibility
This tool supports uncompressed (1), LZW (5), and PackBits (32773) — the three most common TIFF compression types. CCITT Group 3/4 fax compression (3/4), JPEG-in-TIFF (6/7), and DEFLATE (8) will trigger a fallback message. Use a desktop tool like LibreOffice to pre-convert these.
Quality for TIFF Content
tip → quality
TIFF is lossless, but the PDF is re-encoded as JPEG. For scanned text documents, use quality 95–100 to preserve sharp character edges. For photographic TIFFs, 85–92 is indistinguishable from the original at normal viewing sizes and produces significantly smaller PDFs.
Landscape for Panoramas
tip → orientation
Many scientific and cartographic TIFFs are wider than tall. Switch orientation to Landscape and use "Fit to Page" to ensure the full image is visible without clipping.
Batch Multiple TIFFs
tip → batch
You can upload multiple separate TIFF files at once — each becomes a block of pages in the PDF in the order you added them. This is useful for collections of single-page TIFFs that belong in a single document.
